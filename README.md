本拓展僅確保支援 Windows 11 原生檔案管理系統
本拓展將自動以系統管理員身分執行

快捷鍵功能列表：
1. F2				: 使位於游標懸停處下方的檔案或資料夾，進入重新命名模式；若無圖示，則改為已選取的第一個單位
2. 滑鼠中鍵			: 使被點擊的檔案或資料夾，進入重新命名模式
3. Shift + 滑鼠中鍵	: 於新索引標籤開啟指定資料夾
4. Ctrl + 滑鼠中鍵	: 於新索引標籤開啟指定資料夾，並切換至該所引標籤
4. Alt + 滑鼠中鍵	: 開啟詳細內容

其他支援功能：
1. 滑鼠左/右鍵雙擊空白處	: 返回父目錄
2. 滑鼠左/右鍵三擊空白處	: 返回上一頁
